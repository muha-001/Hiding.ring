# Hiding.ring

لعبة **Golden Ring: International Tournament Edition** تعمل مباشرة في المتصفح دون خادم أو عملية بناء.

## هيكلية المشروع

```text
Hiding.ring/
├── index.html              # الهيكل الدلالي للواجهة ونقاط تحميل الموارد
├── README.md               # تعريف المشروع وطريقة تشغيله
├── ANALYSIS_AR.md          # تقرير التحليل السابق
├── src/
│   ├── css/
│   │   └── styles.css      # جميع قواعد التصميم والاستجابة والحركة
│   └── js/
│       └── app.js          # منطق اللعبة والصوت والجسيمات وربط الأحداث
└── tools/
    └── split_project.py    # أداة إعادة الهيكلة المستخدمة لمرة واحدة
```

## طريقة التشغيل

يمكن فتح `index.html` مباشرة في متصفح حديث. تعتمد الصفحة على Google Fonts وFont Awesome عبر CDN، ولذلك يلزم اتصال بالإنترنت لظهور الخطوط والأيقونات الخارجية. يمكن لاحقًا إضافة خادم تطوير بسيط أو أداة بناء عند بدء تقسيم JavaScript إلى وحدات مستقلة.

## مبدأ الحفاظ على السلوك

تم نقل CSS من داخل الصفحة إلى `src/css/styles.css`، ونقل JavaScript إلى `src/js/app.js`، مع استبدال معالجات `onclick` المضمنة بربط مركزي للأحداث. لم تتغير قواعد اللعبة أو المستويات أو المؤقتات أو النقاط أو المؤثرات الصوتية والبصرية.

## مسار التطوير التالي

عند إضافة ميزات جديدة، يُفضّل تقسيم `app.js` تدريجيًا إلى وحدات مثل `config/levels.js` لإعدادات المستويات، و`core/state.js` لحالة الجولة، و`game/game-logic.js` لقواعد اللعبة، و`audio/audio-engine.js` للصوت، و`effects/particle-system.js` للمؤثرات، و`ui/dom.js` للتعامل مع عناصر الصفحة. هذا التقسيم مؤجل عمدًا حتى لا يتغير سلوك النسخة الحالية.
